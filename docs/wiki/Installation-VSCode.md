The ZW edition VS Code extension works in Visual Studio Code and compatible VS Code forks such as Devin. It adds editor commands for `.http` files, request selection, response previews and a more interactive workflow.

## Install

Install the extension from the Open VSX Registry:

[httpYac (ZW edition) - Rest Client – Open VSX Registry](https://open-vsx.org/extension/zerowiggliness/vscode-httpyac-zw)

## When to use it

Use the extension when you want to run requests from the editor, inspect responses next to the request file, and keep request authoring close to the code you are testing.

For CI, scripted usage, or fork-only runtime features, prefer the [CLI](Installation-CLI) or [Docker](Installation-Docker).

> [!NOTE]
> **ZW edition:** the extension is maintained at [ZeroWiggliness/vscode-httpyac](https://github.com/ZeroWiggliness/vscode-httpyac), with patches and updates based on the original work by Andreas Weber. See [ZW edition differences](ZW-Edition-Differences).
